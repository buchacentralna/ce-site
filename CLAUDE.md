# Сайт «Буча Центральна» — інструкція для Claude Code

Статичний сайт: три прототипи сайту-візитки церкви АСД «Буча-Центральна». Без збірки й залежностей:
HTML + CSS в кожному `index.html`, фото в `assets/`. Факти для текстів — тільки з `CONTENT.md`.

## Dev mode: запустити сайт і дати публічне посилання (ngrok)

Коли користувач просить «запусти сайт», «покажи сайт», «дай посилання другу» — роби так:

1. **Перевір інструменти:** `python3 --version` і `ngrok version`.
   - Немає `ngrok`: macOS — `brew install ngrok`; Linux/Windows — https://ngrok.com/download.
     Встановлення — це зміна на машині користувача, спершу спитай.
   - Немає `python3`: попроси користувача встановити його (https://www.python.org/downloads/).
2. **Перевір, що ngrok залогінений:** `grep -q authtoken "$(ngrok config check 2>&1 | sed -n 's/.*file at //p')"`
   (або `serve.sh` впаде з `ERR_NGROK_4018`). Якщо authtoken не задано —
   НЕ вводь токен сам і не проси вставити його в чат. Попроси користувача:
   зареєструватися на https://dashboard.ngrok.com (безкоштовно), скопіювати authtoken
   і виконати у твоєму промпті `! ngrok config add-authtoken <токен>`.
3. **Запусти** з кореня репозиторію у фоні (Bash з `run_in_background`):
   `./serve.sh` (інший порт: `PORT=8091 ./serve.sh`).
   Скрипт сам піднімає `python3 -m http.server` і ngrok, друкує обидва посилання і тримає їх,
   доки працює; Ctrl+C / kill скрипта зупиняє обидва. Логи — у `.run/` (в `.gitignore`).
4. **Перевір** перед тим, як віддати посилання: `curl -s -o /dev/null -w '%{http_code}' http://localhost:8090/`
   і те саме для публічного URL з заголовком `-H 'ngrok-skip-browser-warning: 1'` — обидва мають дати `200`.
5. **Дай користувачу:** публічне посилання з виводу (`https://….ngrok-free.app/`) і локальне
   `http://localhost:8090/`. Попередь: при першому відкритті ngrok показує сторінку-попередження —
   треба натиснути «Visit Site».

Важливо:
- Локально відкривати саме `localhost`, не `127.0.0.1`: з `127.0.0.1` YouTube-вставки показують
  «This video is unavailable».
- Посилання живе, поки працює `serve.sh` і машина не спить. Після перезапуску URL буде новий.
- Windows без bash (Git Bash / WSL): запусти дві команди в окремих терміналах:
  `python -m http.server 8090 --bind 127.0.0.1` і `ngrok http 127.0.0.1:8090`; URL — у вікні ngrok.

## Структура

- `/` (`index.html`) — вибір варіанту; `/v1/`, `/v2/`, `/v3/` — три дизайни (див. `README.md`)
- `CONTENT.md` — єдине джерело фактів (адреса, розклад, люди, відео). Не вигадувати те, чого там нема.
- `assets/photos/` — вибрані фото; `assets/fb/`, `assets/ig/`, `assets/yt/` — сирі завантаження з соцмереж.
